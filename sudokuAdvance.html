Sudoku Advance!

“Sudoku Advance!” is a pure passion project of mine, I love to sit and solve a sudoku whenever and wherever I can, so I thought why not make myself a GBA version in hopes of getting better solving them as well as further developing my skills with C++ and Butano.
When making this project I had to make a sudoku puzzle generator that was fast enough to do it on the GBA’s processor, I knew that the system wouldn’t be fast enough to generate the harder boards, so I used it for the 2 easier difficulties. For the hard boards I made a program in regular C++ that would generate any number of boards with any starting number of tiles filled I desired and then it would format then in a way that “Sudoku Advance!” would be able to read them and randomly select one for the player to player. Even though I added a few thousand pre-made boards to the game I thought and nice addition would be to scramble the board a little by mirroring the rows and columns and to shuffle the numbers around so the player will never see the same board twice.
The real fun of this project is that I am working with the old hardware of the Game Boy Advance, having just barely enough sprites to draw the 81 numbers on the board made adding the notes, which to me were a must, a fun challenge a one that was very rewarding to solve. The method was to mask parts of the note sprite to only show the desired notes of the player, and another fun addition was to have them use different indices in the sprites palette so I could easily highlight the currently selected number so add make the board easier to read on this tiny resolution.
Unlike my previous projects on the GBA this one can save allowing me to have made a stats screen. This was a great as I love to see my own play records and I’m always trying to beat out my own personal best time so to be able to do this was so cool for me and this being a game of mine I will play often.
